Хранение данных

  • localStorage: имя + персонаж сохраняются на телефоне. При повторном подключении — автозаполнение
  • Server (players.js): поле name + character хранятся на объекте player
  • Host отображает: имя + blob персонажа вместо "P1 🐱"
  • Narrator использует имена: "Alex stumbled!" вместо "Player 2 stumbled!"
